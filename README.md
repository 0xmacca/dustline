DUSTLINE is a round-based tactical FPS: 5v5 charge plant/defuse on the Solar Flats map, with an economy and buy menu, grenades, bot squads and a live HUD.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome.
